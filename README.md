# MNIST Handwritten Digit Classification using ANN

A beginner-friendly Deep Learning project that uses an Artificial Neural Network (ANN) to recognize handwritten digits from the MNIST dataset.

## 📌 Project Overview

Handwritten digit recognition is a classic Computer Vision and Deep Learning problem.

In this project, an ANN model is trained on the **MNIST dataset** to classify handwritten digits from **0 to 9**.

The project covers the complete workflow:

- Loading the MNIST dataset
- Exploring and visualizing images
- Preprocessing image data
- Normalizing pixel values
- Converting labels into categorical format
- Building an ANN using Keras Sequential
- Training the model
- Evaluating the model
- Visualizing training performance
- Predicting handwritten digits from a custom image

---

## 🎯 Objective

The main objective of this project is to build a neural network that can identify which digit is present in a handwritten image.
